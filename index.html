01

Perfil

Soy Técnico Electrónico y estudio la Licenciatura en Gestión de Tecnología de la Información en UADE (2.º año). Antes de escribir código trabajé en planta: en control de calidad de troqueles y en el seguimiento de pedidos y despachos de una fábrica de cartón corrugado.

Eso me dio algo que no se aprende en un aula: entender cómo funciona un negocio por dentro, dónde se pierde tiempo y qué problemas se pueden resolver con tecnología. Hoy combino esa mirada práctica con desarrollo web y cloud.

Proyecto destacado

TurnoBot — turnos por chat para negocios

Asistente que entiende cómo escribe la gente (“corte y barba el viernes a la tarde con Lucas”), revisa la agenda real y reserva sin superponer turnos. El dueño tiene un panel con login, agenda por profesional y estadísticas de ingresos y ocupación.

  • API REST en Java con Spring Boot, JPA y Spring Security con JWT
  • Intérprete de lenguaje natural en castellano y conversación como máquina de estados
  • 29 tests automáticos (JUnit) que corren en GitHub Actions en cada cambio
  • Publicado con Docker en Render y frontend React en GitHub Pages
